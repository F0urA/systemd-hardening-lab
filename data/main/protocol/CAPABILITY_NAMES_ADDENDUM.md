# Абляция: исправление имён запуска, без изменения профилей

Первый запуск `scenarios-v005/20261012-105855` ошибочно запросил имена
P1c+ADMIN/P1c+PTRACE/P1c+DAC/P1c+CHROOT из текста протокола. Генератор сохранил
реальные файлы P1cADMIN/P1cPTRACE/P1cDAC/P1cCHROOT (без знака `+`).
Поэтому NOT_FUNCTIONAL первого запуска означает отсутствие файла, а не
наблюдавшийся функциональный отказ этих вариантов. E3 тогда не проверено.

Повтор заранее назначается со списком
P0 P1r P1c P1cADMIN P1cPTRACE P1cDAC P1cCHROOT.
Используется scenarios_v005.sh из frozen-timing, содержимое ранее построенных
профилей не меняется. Проверка описательная, не входит в нагрузочную семью M.
Она выполняется только после завершения других нагрузочных процессов.
Первый набор остаётся в raw-vm без исправления строк.
