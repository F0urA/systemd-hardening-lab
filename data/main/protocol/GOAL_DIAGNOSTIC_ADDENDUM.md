# Исправление диагностики после первого запуска сценариев

Первый новый запуск scenarios-v005/20261012-105745 сохранён без изменений.
Redis возвращает `ERR` при отказе SAVE, не передавая errno клиенту. Поэтому
первоначальный fail-closed разбор правильно отметил такие исходы UNEXPECTED,
но не мог различить отказ защиты и другую ошибку. Журнал Redis подтвердил
Permission denied либо Read-only file system для точного тестового каталога.

Во втором запуске сохраняется журнал каждой ячейки (unit, текущий PID, epoch
начала и точный target). BLOCKED допускается только при явном соответствующем
отказе доступа в ответе или таком журнале. Неизвестная ошибка остаётся UNEXPECTED.
Операции, профили, цели, DAC и критерий результата не меняются. Это исправление
диагностики сделано после наблюдения первоначальных сценарных данных, а не
независимо от них. Первый набор не перезаписывается и в анализ не подмешивается.
Статистический код и уже замороженные параметры нагрузки не меняются.
