# Последовательная очередь после основных измерений

Подготовлена 12.10.2026, пока основная R2 ещё выполняется. Это исполнительная
очередь для уже зафиксированных этапов, не новый статистический протокол.
Основные серии не перезапускает; ждёт выхода их контроллера и finished marker.

Порядок: проверенный первый анализ → единственный предусмотренный добор →
окончательный анализ → полный F-контракт CAP-вариантов и исправленная
CAP-абляция → отдельная exploratory
mount-state матрица → установка/регистрация/измерения memcached. Исходный
скрипт очереди и SHA256 фиксируются до её запуска. Только родитель управляет ВМ.

Для memcached заранее разрешён один технический повтор всей неуспешной серии
каждого look; неполный предыдущий результат сохраняется, не объединяется с
успешным повтором и не даёт дополнительного статистического просмотра.
Третий look запрещён. Замороженные M/K, нагрузка, кандидаты и пороги неизменны.

Установка memcached выполняется лишь после нагрузок прежних служб. Проверенная
транзакция ALT p11: memcached 1.6.42-alt1, один новый пакет, без обновлений или
удалений. Любое изменение этой транзакции требует ручной проверки. До установки
пакет, штатный unit и порты 11211/11212 отсутствовали. Штатный новый unit временно
маскируется до установки на время текущей загрузки, а после установки —
постоянной административной маской; автозапуск отключается, и он
оставляется неактивным; отдельный экспериментальный unit слушает
только 127.0.0.1:11212, UDP отключён. Существующие службы не замещаются.
Конфигурация/файл штатного unit не редактируются; ограничен только запуск
нового штатного сервиса, чтобы он не стал неожиданным публичным listener
сейчас или после перезагрузки.

Недоступные/ошибочные этапы сохраняют статус и журналы. В автоматической очереди
нет подбора параметров по результатам, публикации, изменения SSH или паролей.
Её finished marker означает только окончание очереди, а не успешность всех
экспериментов. Родитель отдельно проверяет сырые данные, хеши и восстановление.
