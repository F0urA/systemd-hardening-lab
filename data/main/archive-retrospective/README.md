# Пересчёт архивных границ

Это старые данные этапов v003/v004, переименованные в исходном архиве в v005.
Они не являются измерениями текущего запуска и не объединяются с ними.

`bounds.csv` содержит 21 контраст из семи полных сохранённых серий. Использована
неизменная функция v005, delta=5%, alpha=0,05/(M×2). Для консервативного
сопоставления таблиц взяты текущие M=7 для Nginx и M=5 для Redis/PostgreSQL;
отдельные старые абляции групп CPU имеют M=3. Эта политика пересчёта выбрана
ретроспективно и не выдаётся за предрегистрацию прежних экспериментов.

Из-за другого хоста, недоступной теперь проверки прежних часов и отсутствия
расширенного обязательного контракта в старой таблице здесь нет нового допуска
F или рекомендации профиля. UNRESOLVED_ARCHIVE означает неопределённость по
пересчитанным границам, не разрешение повторно смотреть старые данные.

Прежние выводы «выбрать P0» в архивном отчёте не переносятся в v005:
окончательная процедура явно запрещает P0 как исход выбора.
