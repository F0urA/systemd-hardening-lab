# systemd-hardening-lab

Материалы статьи «Экспериментальная оценка защитного эффекта и стоимости профилей hardening
системных служб Linux средствами systemd»: настройка служб и профили ограничений, скрипты стенда,
измерений и анализа, сырые результаты и команда, которая заново получает из них таблицы статьи.

## Что где лежит

```
README.md               этот файл
reproduce_v007.py       пересчёт таблиц статьи из сырых данных (см. ниже)
docs/
  EXPERIMENTS_v005.md   карта: раздел статьи → скрипт и параметры → каталог с результатом
  SANITIZATION_v007.md  что изменено при подготовке пакета к публикации
  history/              рабочие инструкции, написанные до основных измерений
stand_v005/             настройка служб
  units/                unit-файлы служб Nginx, Redis, PostgreSQL и модельного процесса
  conf/                 конфигурации Nginx и Redis
  profiles/             профили ограничений systemd (P0–P6 и варианты) для каждой службы
  probes/               зонды: микропроверки изоляции и проверки целей нарушителя
  tls_v005/             конфигурация для проверки TLS
scripts_v005/           скрипты
  setup_stand_v005.sh   сборка стенда с нуля; GUIDE_v005.md — порядок запуска
  *_v005.sh, *_v005.py  измерения (нагрузка, функция, цели, абляция, монтирование) и анализ
  protocol_*.txt, procedure_v005.txt   процедура и протоколы, зафиксированные до измерений
  orchestration_v005/   очередь серий на стенде
  analysis_v005/        анализ на стенде и проверки отчёта
  host_v005/            вспомогательные скрипты хоста (выгрузка результатов, монитор)
  tests_v005/           тесты
data/
  main/                 основные измерения — все числа раздела 6 статьи
    raw-vm/             сырые результаты (7587 файлов) и манифест SHA256-CLOSED-RESULTS.txt
    analysis-first-look/, analysis-final/   первый и окончательный анализ
    protocol/           записи фиксации до измерений: RUN_PROTOCOL.md, *_FREEZE*, архивы *-frozen.zip
    frozen-*/           распакованные копии исполнявшихся версий скриптов
    reports/            отчёт о выполнении (report_v005.md), статус, проверки полноты и чисел
    logs/               журналы выгрузки результатов и монитора хоста
    executed/           копии скриптов, исполнявшихся на хосте
    archive-retrospective/, resume-context-20261013/   пересчёт архивных серий, контекст продолжения
  derived/              производные таблицы для статьи (точечные оценки, проверка PostgreSQL)
  preliminary/          предварительные измерения (этапы 1–2); с основными не объединяются
```

Профиль — это надстройка к unit-файлу службы: например, `stand_v005/profiles/nginx/P1c.conf`. Сырой
результат одного измерения — файл в каталоге серии, например
`data/main/raw-vm/nginx/benchmark-v005/20261012-175912/`: `results.csv` по всем блокам и вывод
генераторов нагрузки по каждому измерению.

## Воспроизведение расчётов

```
python reproduce_v007.py          # полная проверка (около минуты)
python reproduce_v007.py --quick  # без сверки сырых файлов с манифестом
```

Виртуальная машина не нужна. Скрипт делает следующее:
- сверяет сырые данные с манифестом, а архивы исполнявшихся скриптов — с хешами, записанными до измерений;
- заново строит из принятых серий таблицу критериев (границы с поправкой, исходы добора);
- повторяет выбор по правилам A, A+ и B, 24 политики оператора и выбор с обязательными целями;
- считает прямые контрасты, точечные оценки и проверку t-границ PostgreSQL перестановочными границами;
- сравнивает всё с сохранёнными результатами.

Нужны Python 3.9+ и numpy (только для последнего шага).

## Повторение измерений

Порядок работы на стенде описан в `scripts_v005/GUIDE_v005.md`, соответствие разделам статьи — в
`docs/EXPERIMENTS_v005.md`. Скрипты копируются на ВМ вместе со `stand_v005/`. Значения, привязанные к
машине, задаются параметрами `SLAB_BASE`, `SLAB_SSH_HOST`, `SLAB_PYTHON`, `SLAB_SH`. На стенде
результаты пишутся в `results_v005/`; в этом репозитории они разложены по `data/`.

## Замечания

- Точные исполнявшиеся версии скриптов лежат в `data/main/protocol/*-frozen.zip` и `data/main/frozen-*/`;
  `scripts_v005/` — их переносимая редакция с той же логикой.
- Драйверы `driver_primary_v005.sh` и `driver_primary_corrected_v005.sh`, которые запускали первые
  серии, в пакет не вошли: известны только их хеши (см. `docs/EXPERIMENTS_v005.md`).
- При подготовке пакета из записей удалены локальные пути компьютера, на котором шли измерения, а
  ссылки в отчётах переведены на новые места файлов. Сырые данные не изменялись. Перечень изменений с
  хешами до и после — `docs/SANITIZATION_v007.md`.
